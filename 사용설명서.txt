 발전부문 배출권 가격 예측 MVP — 처음 사용하는 분을 위한 설명서
 국립창원대학교 identity 팀
====================================================================

이 프로그램은 발전부문 배출권(온실가스 배출권) 가격을 앞으로 1년간
예측해서 보여 주는 대시보드입니다.

구조는 두 부분으로 나뉘어 있습니다.
  - 백엔드(backend) : 파이썬 서버. 실제 예측 계산을 하고, 화면도 함께 제공합니다.
  - 프론트엔드(frontend) : 화면(React). 백엔드에 예측을 요청해서 보여 줍니다.

★ 중요: 프론트엔드 혼자서는 동작하지 않습니다.
  백엔드 서버를 켜면, 그 서버가 화면까지 같이 띄워 줍니다.
  (즉 "서버 하나만 켜면" 됩니다.)


--------------------------------------------------------------------
 폴더 구성
--------------------------------------------------------------------

  backend/
    app.py                            ← 파이썬 서버 프로그램
    requirements.txt                  ← 필요한 파이썬 패키지 목록
    발전부문_배출권_분석_마스터셋.csv   ← 예측에 쓰는 데이터
  frontend/
    index.html                        ← 화면 (백엔드가 자동으로 띄워 줌)
  README.md                           ← 요약 안내


====================================================================
 접속 방법
====================================================================

■ 그냥 사용만 할 경우 (가장 쉬움)
  아래 배포된 주소로 접속하면 됩니다. 설치할 것이 없습니다.

      https://epfm.onrender.com/

  * 무료 서버라서, 한동안 아무도 안 쓰면 잠들어 있습니다.
    첫 접속 때 화면이 뜨기까지 수십 초(최대 1분) 걸릴 수 있습니다.
    잠시 기다리거나, 오류 화면이 나오면 "다시 시도"를 누르세요.


====================================================================
 내 컴퓨터에서 직접 실행하는 방법 (서버 하나만 켜면 됩니다)
====================================================================

준비물: 컴퓨터에 파이썬(Python 3.9 이상)이 설치되어 있어야 합니다.
        (https://www.python.org 에서 설치)

1) 명령 프롬프트(Windows) 또는 터미널(Mac)을 엽니다.

2) backend 폴더로 이동합니다. 예:
       cd 경로/deliverable/backend

3) 필요한 패키지를 설치합니다. (처음 한 번만)
       pip install -r requirements.txt

4) 서버를 실행합니다.
       uvicorn app:app --host 0.0.0.0 --port 8000

5) 웹 브라우저를 열고 주소창에 아래를 입력합니다.
       http://localhost:8000

   → 잠깐(1~3초) 뒤 대시보드 화면이 나타납니다.

6) 서버를 끄려면 터미널에서 Ctrl + C 를 누릅니다.

* 화면이 "서버에 연결할 수 없습니다" 로 나오면:
  - 위 4)번 서버가 켜져 있는지
  - 주소(포트 8000)가 맞는지 확인한 뒤
  - 화면의 "다시 시도" 버튼을 누르세요.

* index.html 파일을 그냥 더블클릭하지 마세요.
  화면은 뜨지만 백엔드에 연결하지 못해 오류 화면이 나옵니다.
  반드시 위 5)번처럼 http://localhost:8000 으로 접속하세요.


--------------------------------------------------------------------
 화면 사용법
--------------------------------------------------------------------

[왼쪽 사이드바 = 설정하는 곳]

  • 데이터 추가/제거
      "파일 선택" 한 곳에서 배출권 가격, 원단위, 공급(할당량),
      수요(배출량) CSV/XLSX를 여러 개 동시에 선택합니다.
      백엔드가 파일명과 컬럼 구조를 분석해 종류를 자동 판별하고,
      월별 동기화·결측치 보정·수급지수 계산·모델 재학습 후
      그래프에 즉시 반영합니다. 선택 파일은 목록에서 개별 제거하거나
      "전체 제거"로 기본 데이터셋 상태로 복원할 수 있습니다.
      실제 가격 파일만 추가해도 해당 년월은 실제값으로 교체됩니다.
      실제값 이전에 비어 있는 월은 기존 예측값으로 연결하고,
      실제값 다음 달부터 새 실제값을 기준으로 다시 연쇄 예측합니다.

  • 시뮬레이션 방식 선택
      - 자동 가격 예측 : 과거 패턴만으로 알아서 예측합니다. (기본값)
      - 사용자 수치 조절 : 내가 직접 조건을 바꿔 가며 예측해 봅니다.
                          (선택하면 아래에 조절 막대가 나타납니다.)

  • 1) 예측 알고리즘 엔진 선택
      - OLS 수식 모델      : 통계 수식(statsmodels) 기반 예측
      - AI 머신러닝 모델   : 랜덤포레스트(scikit-learn) 기반 예측
      두 개를 바꿔 가며 결과를 비교해 볼 수 있습니다.

  • (사용자 수치 조절일 때만)
      - 할당량 여유 지수 변동 : 배출권이 남는/모자라는 정도를 조절
      - 발전 온실가스 원단위 변동 : 발전 효율 변화(%)를 조절
      - 정산기 시즌 적용 방식 : 4~6월 정산기(매물 몰리는 시기) 적용 규칙

  * 설정을 바꿀 때마다 백엔드에 다시 계산을 요청해 화면이 갱신됩니다.

[가운데/오른쪽 = 결과 보는 곳]

  • 예측 요약 : 다음 달 예측가, 1년 후 예측가, 변동 범위
  • 월별 예측 명세표 : 13개월치 예측을 표로 정리
      → 표 아래 파란 버튼으로 CSV 파일로 저장할 수 있습니다.
  • 예측 곡선 그래프 :
      - 회색 실선 = 과거 실제 가격
      - 파란 점선 = 앞으로의 예측
      - 파란 음영 = 예측 구간

[8월 모델 검증]

  • 8월 예측 오차 백테스트
      7월에 내려받은 예측표와 8월 KRX 실제가 파일을 각각 선택합니다.
      같은 년월을 1:1 매칭하여 MAE, RMSE, MAPE, 평균 편향을 표시합니다.
      파일이 없으면 "최근 12개월 교차검증"으로 과거 성능을 확인할 수 있습니다.

  * 업로드 데이터와 연결 예측은 실행 중인 서버 메모리에 적용됩니다.
    서버가 재시작되면 저장소의 기본 CSV로 복원됩니다. 영구 반영하려면
    생성 CSV를 backend/발전부문_배출권_분석_마스터셋.csv로 교체해 커밋하세요.


--------------------------------------------------------------------
 자주 묻는 질문
--------------------------------------------------------------------

Q. 프론트엔드만 따로 열면 안 되나요?
A. 안 됩니다. 예측 계산은 백엔드가 합니다. 백엔드 서버를 켜면
   화면(프론트엔드)까지 함께 제공되므로, 서버 하나만 켜면 됩니다.

Q. 인터넷이 꼭 있어야 하나요?
A. 화면을 그리는 기본 라이브러리를 처음 불러올 때 인터넷이 필요합니다.
   예측 계산은 내 컴퓨터의 백엔드 서버가 하므로 외부 연결은 필요 없습니다.

Q. 다른 컴퓨터/서버에 올리고 싶어요.
A. backend 폴더를 서버에 올리고 uvicorn 으로 실행하면 됩니다.
   프론트엔드를 백엔드와 다른 도메인에 두려면 frontend/index.html 안의
   window.__API_BASE__ 값을 백엔드 주소로 바꾸세요. (자세한 내용은 README.md)

Q. 내 데이터를 넣으려면?
A. 왼쪽 "데이터 추가/제거"의 파일 선택 버튼에서 원본 파일을 한꺼번에
   선택하세요. 완성된 표준 마스터셋 한 개만 선택해도 바로 적용됩니다.
